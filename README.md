## 🔒 Segurança e Versionamento

O repositório já está configurado com [`.gitignore`](./.gitignore) para evitar que arquivos sensíveis ou pesados sejam enviados ao GitHub:
- Arquivos de credenciais (`.env`)
- Ambientes virtuais (`.venv`, `venv`)
- Cache do Python (`__pycache__`)
- Dependências e pacotes locais (`node_modules`)
